## 二、TRAE 实践截图（3 张，需你在 TRAE 里截）

| # | 截什么 | 怎么截 | 要能看清什么 |
| --- | --- | --- | --- |
| A | 任务 A 会话 | 打开历史会话 → 滚到「问题拆解 / 五视图方案」那条回复 | 标题、Session ID、你的提问 |
| B | 任务 B 会话 | 滚到「GraphQL 批量补全 673 个仓库」或「24 次修订差分」 | 标题、Session ID、产出数字 |
| C | 任务 C 会话 | 滚到「13 个问题」表格 + 后续修复 | 标题、Session ID、问题清单 |

截图要点：
- 一定要带上 **Session ID** 或会话链接（评委要核验）。
- 一张图里同时出现「你的提问」和「TRAE 的执行结果」最有说服力。
- 如果一屏放不下，允许同一会话截 2 张，但 3 个会话必须各有 1 张。

## 三、90 秒演示脚本

| 时间 | 画面 | 旁白（可直接念） |
| --- | --- | --- |
| 0–6s | 首屏全景，鼠标轻移 | 「Awesome 生态有 678 条清单，但入口是一篇几万字的文档。」 |
| 6–14s | 在搜索框输入「agent」，结果实时收敛 | 「想找某个方向还剩哪些清单，通常只能 Ctrl+F。」 |
| 14–24s | 切到分类地图，点一个分类下钻，再点条目 | 「我把它做成了一张地图：面积是条目数，颜色是健康分，点两下就到具体清单。」 |
| 24–34s | 切到关系图谱，点分类节点 | 「图谱看的是从属关系——哪个分类撑着整个生态，一眼可见。」 |
| 34–48s | 切到检索榜单，按星标排序，打开归档过滤，点收藏 | 「榜单是真正干活的地方：排序、语言、归档、收藏，筛完直接分享 URL。」 |
| 48–58s | 切到生态时间轴 | 「时间轴还原了上游 24 次修订和仓库活跃度，能看出生态在哪一年变冷。」 |
| 58–68s | 切到数据洞察，指向停滞清单 | 「洞察回答的是『整体健不健康』，而不是某一条有多好。」 |
| 68–78s | 按下 `Ctrl+K`，输入分类名回车 | 「全站键盘可操作：命令面板、方向键切标签、表格行回车开详情。」 |
| 78–86s | 手机尺寸录屏，切换视图 | 「移动端同源，所有触控目标实测不小于 44 像素。」 |
| 86–90s | 回到首屏，出现结语 | 「4 个静态文件，零依赖，国内网络直接打开。」 |

录制建议：
- 1080p / 30fps，浏览器窗口固定 1440×900，隐藏书签栏。
- 不要配音也可以，但字幕要写清五视图各自解决什么问题。
- 结尾停 2 秒在首屏，方便评委截图。
